# Optuna TPE — оптимизатор весов θ для Snake

## Метод

**TPE (Tree-structured Parzen Estimator)** — байесовский метод оптимизации
из библиотеки [Optuna](https://optuna.org/). Не входит в scipy.

Вместо случайного поиска TPE строит вероятностную модель: на каждом шаге
делит все предыдущие точки на «хорошие» (top-γ%) и «плохие», затем
сэмплирует новые θ из области хороших. Это даёт быструю сходимость даже
на шумной целевой функции.

## Установка

```bash
uv add optuna
```

## Запуск оптимизации

```bash
uv run python optuna_tpe/optimizer.py
```

## Оценка результата

```bash
# Baseline vs Optuna TPE best по всем seeds:
uv run python optuna_tpe/evaluate.py

# Проверить конкретные веса:
uv run python optuna_tpe/evaluate.py 17.48 1.11 5.82 -1.13
```

## Визуализация в браузере

## Параметры оптимизатора

| Параметр | Значение | Описание |
|---|---|---|
| `N_TRIALS` | 300 | Число точек которые TPE попробует |
| `MAX_STEPS` | 400 | Макс. шагов змейки за партию |
| `BOUNDS` | (−20, 20) | Диапазон поиска каждого веса |
| `seed` | 42 | Воспроизводимость TPE |
